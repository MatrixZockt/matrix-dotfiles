The middle island — token usage while busy

Whenever the server is online and a slot is actually working, the top bar's middle cluster grows a token counter and a lock mark. The lock is the honest part: while locked, a horizontal swipe over the popup is ignored, so a fast gesture can never yank you off the tab while a generation is in flight. The moment the last slot goes idle — or the server stops — the counters and the lock both disappear and swiping works normally again.

How the lock is decided: online and at least one slot with n_decoded increasing between two polls. Idle servers and offline servers never lock. Nothing about the lock is a mode flag you have to set by hand — it is derived from the same counter that fills the counter, so the two can never disagree.
