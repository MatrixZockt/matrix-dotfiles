Three designs for the System tab of the middle popup. All keep the four live readings on top (CPU / RAM / GPU / temp) and put the static machine facts — the stuff that never varies — into categories, so the tab stops being a wall of charts.

One glance = everything. The facts are grouped into bordered cards (Machine / CPU & memory / Graphics & storage), two columns, no interaction needed. Live strip stays on top.
