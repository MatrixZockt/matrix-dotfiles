Design templates

Twelve color templates, each generated by the shell's own Material engine (scripts/colors/generate_colors_material.py) from a seed accent and a scheme — the same code path your wallpaper theming already uses. Every mockup below reimplements the shell's real colour maths and layout constants, so a palette that looks right here looks right in Hyprland. Nothing is applied: this page only writes the files in themes/templates/. Dark and light palettes exist for every template, and the wallpaper behind the mockups is a stand-in tinted from the palette, not your real wallpaper.
