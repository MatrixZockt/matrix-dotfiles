# Words whisper should expect to hear. One term per line; `#` starts a comment.
#
# HOW THIS LIST IS USED, and why it is ordered the way it is.
#
# dictate.sh sends these words WITH EVERY REQUEST as whisper's initial prompt
# (dictate_prompt), so editing this file takes effect on the next hold of SUPER:
# nothing is restarted, nothing needs reloading, and a dictation is never lost
# to a server coming back up. Before that, an edit restarted the whole server
# and the next dictation paid for it -- once with 39 seconds.
#
# The decoder reads the list as text it has "just written", which is why a name
# here is spelled correctly instead of phonetically -- but only the last half of
# its text context is available for a prompt (~224 tokens, and this list runs
# ~2.7 characters per token), and past that it drops from the FRONT. Two rules
# follow:
#
#   * keep the whole list under ~560 characters (dictate.sh stops adding terms
#     past that, so a runaway list silently loses its tail);
#   * put what hurts most LAST -- the end of the list is both what survives any
#     truncation and what sits closest to the audio.
#
# For a name that comes out wrong regardless, use ~/.config/ii-dictate/fixes.txt
# instead: that is applied to the finished sentence and cannot be ignored.
